# Analyseur de mots de passe

Un programme Python qui permet d'évaluer la sécurité d'un mot de passe et de générer un nouveau mot de passe.

## Fonctionnalités

- Vérification de la longueur du mot de passe.
- Détection des majuscules et minuscules.
- Vérification de la présence de chiffres.
- Vérification des caractères spéciaux.
- Détection des mots de passe trop courants.
- Génération automatique de mots de passe.

## Technologies utilisées

- Python 3
- Module random
- Module string

## Lancer le programme

1. Installer Python 3.
2. Télécharger le projet.
3. Ouvrir le terminal dans le dossier du projet.
4. Exécuter :

```bash
python main.py
